; mods.txt — which Lua mods UE4SS loads, and in what order.
; Format: <ModName> : <1 = enabled, 0 = disabled>
; The name must match a directory under $BIN_DIR/Mods/ exactly.
;
; To disable a crashing mod: set it to 0 and redeploy with --mods-only.
;
; NOTE: UE4SS 3.0+ ships both mods.txt and mods.json with the same list.
; We deploy mods.txt only; if the server ever ignores this file, check whether
; a stale mods.json is taking precedence.

; --- our mods -----------------------------------------------------------
; Read-only. Hooks ApplyDamage and polls vitals; never mutates game state.

; !slay, !unstuck, !prime, !status. !slay kills and !unstuck teleports the
